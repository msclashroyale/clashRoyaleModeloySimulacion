### Para MAXIMIZAR VICTORIAS:

1. **Elección de Estrategia:**
   ```
   Tier S: Agresiva (57% winrate)
   → Rush temprano (primeros 60s)
   → Alto daño por elixir (32.5)
   → Gana casi todos los matchups
   ```

2. **Counter-Picking:**
   ```
   Si oponente juega Defensiva → Usa Agresiva (64%)
   Si oponente juega Agresiva  → Usa MenorCosto (58%)
   Si oponente juega MenorCosto → Usa Defensiva (54%)
   Si oponente juega Aleatoria → Usa Agresiva (61%)
   ```

3. **Gestión de Recursos:**
   ```
   Maximiza daño/elixir:
   • No gastes elixir innecesario
   • Trade favorable > Trade parejo
   • Presión constante > Big plays
   ```

4. **Timing:**
   ```
   Con Agresiva: Ataca 0-60s
   Con MenorCosto: Controla 60-90s
   Con Defensiva: Contraataca 90-120s
   ```

5. **Niveles:**
   ```
   Prioriza subir niveles en este orden:
   1. Tu estrategia principal (+1 = +9% winrate)
   2. Counters a estrategias populares
   3. Estrategias versátiles (MenorCosto)
   ```

**Lo que REALMENTE importa (en orden):**

1. **Nivel** (18% por +2) → Sube de nivel

5. **Ejecución** (resto) → Evita errores
